# Python 注释约定

生产代码的模块、公共类、构造器和公共函数使用三双引号的多行 docstring，采用 Google 风格，说明文字使用中文。它们可通过 IDE、help() 和文档工具读取，不以散落在函数中的三引号字符串代替说明。

- 第一行说明职责，空一行后给出必要细节；结束三引号单独一行。
- 函数按需写 Args、Returns 或 Yields、Raises、Notes；参数说明使用真实参数名，写清单位、默认行为和副作用。
- 数据类用 Attributes 描述字段含义，尤其是字符/Token、局部/绝对坐标、空值与顺序。
- 对关键算法的私有函数同样说明输入、输出和不变量；行内 `#` 只解释实现原因，不复述赋值代码。
- 异常、来源精度、未实现能力需与真实代码一致；不在注释里把接口占位写成已完成能力。

Ruff 启用 pydocstyle 的 D 规则和 Google convention，检查文档存在、段落、缩进、结束引号及参数说明。仅关闭不接受中文句号的 D415；测试和迁移文件不强制此文档规则。文字语义与全部 docstring 是否为多行仍需代码审查。

本次公开接口已补齐多行说明；**逻辑与测试的逐项审查从分块组件开始**，其他组件的注释补齐不表示它们已经完成相同深度的逻辑审查。后续沿用“单个行为 → 函数 → 对应测试 → 状态”的检查颗粒度。
